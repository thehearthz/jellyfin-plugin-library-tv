Automatic channels

Credits only speed up for programs whose credits Library TV has found: an Outro media segment, a credits chapter, or Credits detection (see Credits detection below). Hand-built channels set this on their own Content tab.

Automatic channels use the whole library, with commercials and bumpers from the shared Commercial library below. Use the channel builder above for a hand-picked lineup.

Smart channels

Build a channel from what is in your library: any of several genres, years or decades, combined with shows and movies you pick by hand. A program is included when it matches every criterion you fill in (any one of the genres, and any one of the years or decades); the shows and movies you pick always air. Smart channels use the commercials per break and shared commercial library above.

Content restrictions

Keep genres or tags off the air during set hours on every channel, for example horror before 9 pm. A program that would still be playing when a window starts waits until the window ends.

Commercial library

Shared commercials and bumpers for every channel without its own. After Jellyfin finishes starting, and at each library refresh, Library TV reads the year, decade and network from every file and folder name, such as “Nickelodeon Gak 1994.mp4” or “Adult Swim/2000s/bump.mp4”, and sorts each clip to the programs that match it.

How your clips were sorted

Browse and fix clips

Every clip as filed, from your last saved refresh. Open a clip to change its network, year or show, preview it, or see which programs it plays with. Tick several to change them together. Changes apply when you save, and nothing is renamed on disk.

Rules

A rule changes every clip whose folder or file name contains some text, for example everything with “bump” in its name becomes a bumper, or a whole folder is filed under one network. Later rules win, and edits to single clips win over rules.

Credits detection

In the background, after Jellyfin finishes starting, Library TV reads the end of every program on your channels once. Episodes of a show are compared with each other to find their shared closing music; movies, and shows whose credits differ, are checked for a long dark stretch with text. Commercial breaks then fall before the credits, and Credits speed can roll them faster. Credits chapters and Outro segments are used instead when a program has them. It runs at low priority, one file at a time; changed files are read again.
