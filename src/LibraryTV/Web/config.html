Library TV

Virtual channels advance with the clock. No video processing runs when nobody is watching.

Manual channels

Use the library IDs below in Source.LibraryIds. For an exact episode order, add episode IDs to Source.ItemIds and set Shuffle to false. Episodes are ordered by season and episode within each series.

Blocks are checked in listed order. Times use HH:mm; Days uses Sunday=0 through Saturday=6. A block may cross midnight. MaxItemsPerDay=3 schedules three episodes, then uses the channel's default source. Programs finish before the next block begins. CommercialCount inserts ads between programs; Commercials.FolderIds selects a library folder. Transcode=false uses low CPU stream copy; true encodes compatible 720p video and uses more CPU.

Saved guide entries remain fixed until they air. New media enters the rolling tail automatically. Changing a channel ID starts a new schedule and episode rotation. Repeats start only after the selected pool is exhausted; RepeatWhenExhausted=false disables that.
